TRENDMECCA 2026 Q4 운영계획 - 스트림릿 보고 앱

1) 설치:  pip install -r requirements.txt
2) 실행:  streamlit run app.py

기반 자료
- data 폴더의 파일을 자동으로 읽습니다.
  · 파일명에 '목표'가 들어간 엑셀  → 목표매출 (연간매출및 목표 시트)
  · 파일명에 '등급'이 들어간 엑셀  → 상품등급 표
  · 파일명에 '브랜드'가 들어간 엑셀 → 브랜드 재고 (재고액 TOP 10)
- 파일을 바꾸려면 data 폴더의 엑셀을 새 파일로 덮어쓰면 됩니다.
